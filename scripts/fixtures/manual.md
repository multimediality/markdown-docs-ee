## Requirements

- ExpressionEngine 7.2 or later.
- PHP 8.1 or later.

## Installation

1. Copy the folder.
2. Install it.

### Upgrading

Replace the folder and run **Update**.

### Uninstalling

Nothing is kept.

## Usage

Put `{exp:example:tag entry_id="{entry_id}"}` in a template.

| Parameter | Default |
|---|---|
| `entry_id` | none |
